    Hecho con Google ADK, abierto a otros agentes por A2A

    leygo está construido en TypeScript con el Agent Development Kit (ADK) de Google: el coordinador y cada especialista son agentes ADK, con sus herramientas, sesiones y delegación.

    Además habla A2A, el protocolo abierto para que agentes de distintos equipos y proveedores conversen entre sí. Cualquier agente externo puede consultar a leygo; solo necesitas darle un token.

    1. Crea un token en Conexiones A2A y marca qué herramientas puede usar.
    2. Comparte la URL de tu tarjeta (/.well-known/agent-card.json) y el token con quien lo va a usar.
    3. El otro agente pregunta en lenguaje natural y leygo responde, sin mostrarle tu correo, tu calendario ni tu memoria privada.

    Para que te consulten necesitas una URL pública. En un servidor ya la tienes; en tu computador la abres con un túnel (te mostramos cómo). También funciona al revés: leygo puede consultar a agentes A2A de otros, como a uno más de sus especialistas. Mira cómo responde en la demo.

    Instalar

    Necesitas Docker, Node.js 22, un Redis, un Qdrant y la clave de algún proveedor de modelos. Con Gemini basta para empezar.

    1. Clona el repositorio

      git clone https://github.com/JesusMaster/leygo-agent.git
cd leygo-agent

    2. Configura tus claves

      Copia el ejemplo y completa al menos GEMINI_API_KEY, REDIS_HOST y QDRANT_URL. El segundo comando crea tu usuario de la interfaz: pega en .env la línea que imprime.

      cp .env.example .env
npm install && npm run gui:password

    3. Apunta tu dominio y levántalo

      Un registro A hacia tu servidor. Caddy saca el certificado solo.

      echo "DOMAIN=agente.tudominio.cl" >> .env
docker compose up -d

    4. Entra y conecta lo que uses

      Abre tu dominio, inicia sesión y agrega desde Ajustes otros proveedores de modelos, Telegram o Google Workspace. Todo es opcional salvo el modelo.

    ¿No tienes servidor? Córrelo en tu computador con Docker. ¿Lo vas a dejar en producción? La guía paso a paso para un Droplet de DigitalOcean está en docs/DEPLOY.md.

    1. Levántalo en tu computador

      Con DOMAIN=:80 queda en http://localhost, sin certificado.

      git clone https://github.com/JesusMaster/leygo-agent.git
cd leygo-agent
cp .env.example .env
echo "DOMAIN=:80" >> .env
docker compose up -d

    2. Abre un túnel, solo si vas a usar A2A o webhooks

      Te da una URL https://….trycloudflare.com que cambia cada vez que lo inicias. Para una fija, crea un túnel con nombre en Cloudflare y apúntalo a tu dominio.

      Te da una URL https://….ngrok-free.app. Tu cuenta gratis de ngrok incluye un dominio fijo: úsalo con --url para que no cambie.

      cloudflared tunnel --url http://localhost:80
      ngrok http --url=tu-agente.ngrok-free.app 80

    3. Dile a leygo cuál es su URL pública

      Su tarjeta A2A anuncia esa dirección: si no coincide con la del túnel, los otros agentes no llegan.

      A2A_BASE_URL=https://tu-agente.trycloudflare.com
PUBLIC_BASE_URL=https://tu-agente.trycloudflare.com

      Agrégalas a .env y reinicia con docker compose up -d --force-recreate agent.

    4. Crea un token y compártelo

      En Conexiones A2A, con solo las herramientas que quieras. Quien lo use necesita tu URL y ese token.

    El túnel funciona mientras tu computador esté prendido. Y deja una sola copia de leygo encendida: si también lo tienes en un servidor, apaga una, o Telegram y las rutinas responderían dos veces.

    Preguntas

    ¿Dónde quedan mis datos?

    En tu servidor: la base SQLite, Redis y Qdrant son tuyos. Solo sale lo que mandas al proveedor de modelos que elijas. Si usas Ollama, no sale nada.

    ¿Cuánto cuesta?

    leygo no cuesta nada. Pagas tu servidor (un Droplet de 2 GB anda bien, unos US$12 al mes) y lo que consuma el modelo. La interfaz te muestra cuánto costó cada respuesta y te avisa si pasas el presupuesto que definas.

    ¿Necesito Google Workspace?

    No. Sin Google no lee correo, calendario ni reuniones de Meet, pero el chat, los compromisos, las rutinas, los webhooks y tus propios agentes funcionan igual.

    ¿Puede hablar con otros agentes?

    Sí, por el protocolo A2A. Publica su tarjeta en /.well-known/agent-card.json y le das a cada agente externo un token con solo las herramientas que quieras. También puede consultar a agentes de otros.

    ¿Qué pasa si el modelo se cae?

    Si configuras un modelo de respaldo, idealmente de otro proveedor, la petición se repite con él dentro del mismo turno y no te enteras.

    ¿Puedo cambiarle la personalidad?

    Sí. Nombre, forma de responder, qué puede hacer y sus límites se editan desde Ajustes, con historial de versiones para volver atrás.
